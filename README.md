# 🍔 Brasa Urbana — Landing Page para Delivery

Landing page moderna desenvolvida para uma hamburgueria delivery inspirada na experiência visual de aplicativos como iFood.

O projeto foi criado com foco em design moderno, experiência do usuário e apresentação digital para negócios locais.

---

# 🚀 Funcionalidades

* ✅ Landing page moderna
* ✅ Cardápio digital
* ✅ Layout responsivo
* ✅ Seção de produtos
* ✅ Interface inspirada em apps de delivery
* ✅ Navegação intuitiva
* ✅ Design moderno e visual atrativo
* ✅ Integração com WhatsApp
* ✅ Experiência otimizada para mobile

---

# 🛠 Tecnologias Utilizadas

* HTML
* CSS
* JavaScript
